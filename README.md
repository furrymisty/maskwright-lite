# Maskwright Lite

Maskwright Lite is a free mask node for the Blender compositor, made by FurryMisty.

This repository is its public issue tracker.

## Report a bug

Open a new issue: https://github.com/furrymisty/maskwright-lite/issues/new

Please include your Blender version, the Maskwright Lite version, the steps that lead to the problem, and a screenshot or a small .blend file if you can.

Ideas and feature requests are welcome too.
